# Calculadora (versión de práctica)

Calculadora de línea de comandos en Python que guarda un historial de las
operaciones en `historial.txt`.

## Qué hace

- Suma, resta, multiplica y divide dos números.
- Calcula la raíz cuadrada de un número.
- Permite ver y borrar el historial de operaciones.
- Valida la entrada: si no escribes un número, lo vuelve a pedir.

## Cómo ejecutarla

```bash
python calculadora.py
```

Menú de operaciones: `+`, `-`, `*`, `/`, `r` (raíz), `historial`,
`limpiar` y `salir`.

## Aprendido con este proyecto

- Funciones y `return`
- `input()` y validación con `try/except`
- Módulos `math` y `os.path`
- Leer y escribir archivos (el historial)
- Bucle `while True` con condiciones de salida
